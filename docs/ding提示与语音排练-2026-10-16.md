# ding 提示与无动作语音排练

后续现场反馈已将“每次开始收音提示”细化为“每轮台词等待提示，同轮重试不响”，并将句尾静音调为 0.9 秒。当前规则及证据见[台词断句与轮次提示](台词断句与轮次提示-2026-10-16.md)。以下保留上一阶段记录。

本次按现场反馈替代同日先前的前后蜜蜂提示方案。

## 提示规则

- 复用 `resources/ding.wav`，索引时长 0.492 秒，不合成新音效。
- 模型准备完成后，进入唤醒收音前响一次 ding；这次同时作为启动就绪提示，不额外再响一次。
- 每句台词在开麦前响一次 ding；播放后留出 0.12 秒尾音间隔，再开启麦克风。
- 唤醒成功、收音结束、识别结束均不响；安静等待、短噪声、超长片段丢弃不循环鸣响。
- 未匹配台词时，重新进入下一次收音，响一次 ding。
- 关麦并保存录音后直接转文字，不再创建用于并行结束提示的工作线程。

## 当前排练方式

使用 `--repeat --silent-actions`，保留五幕台词匹配、全部配音、配乐和等待，跳过所有实体动作指令。

树莓派运行目录为 `/home/pi/queen_robot`，临时排练服务为 `fenghou-rehearsal.service`。查看日志：

```bash
journalctl _SYSTEMD_USER_UNIT=fenghou-rehearsal.service -f -o cat
```

停止排练：

```bash
systemctl --user stop fenghou-rehearsal.service
```

手动前台排练：

```bash
systemctl --user stop fenghou.service
systemctl --user stop fenghou-rehearsal.service
cd /home/pi/queen_robot
bash scripts/pi_run.sh --repeat --silent-actions
```

这是临时测试。原 `fenghou.service` 的开机启用配置未改变，重启后仍会恢复带动作的正常演出服务。当前排练结束不自动恢复正常演出。
